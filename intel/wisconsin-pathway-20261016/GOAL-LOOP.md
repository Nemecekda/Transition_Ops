# Wisconsin pathway goal and loop — October 16, 2026

## Outcome

Make Transition OPS an understandable starting point for a service member preparing to return or move to Wisconsin, a veteran building civilian life, and a Guard or Reserve member continuing service or returning from orders. Wisconsin is the first deeply reviewed state pathway within a national product, not a new statewide brand or a default imposed on other visitors.

Dean authorized development and explicitly asked for Claude's participation. Publication of this new iteration is separate from the already-completed PR149 release.

## Iteration

1. Inventory existing tools and Wisconsin coverage before adding screens or duplicating content.
2. Verify official entry points and program distinctions. Record source, checked date, audience, conditions and evidence gaps. State selection and intended relocation never establish residency or benefit eligibility.
3. Build the smallest useful connection: a national state-help entry, an optional Wisconsin choice, a concrete next action and progressively disclosed topics, with routes into existing tools.
4. Obtain actual Claude critique of the plan and implementation behavior. Treat its suggestions as review input; policy facts still require primary verification.
5. Test synthetic journeys, including phone-width navigation, readable labels, keyboard focus, refresh/Back/Forward, saved-plan preservation and non-Wisconsin fallback.
6. Correct the largest observed obstacle; repeat only where new evidence warrants it. Record remaining gaps instead of calling the directory complete.

## Coverage inventory

Benefits review and county/tribal assistance; work and career change; education/training; housing and financial hardship; health and support; family/survivor support; taxes; professional licensing; business ownership; records and transition planning; ongoing Guard/Reserve service; return from activation; reserve retirement. The inventory is an audit checklist, not a claim that every benefit or individual entitlement is already covered.

## First-iteration acceptance

- National visitors can use existing tools without choosing Wisconsin or filling a new profile.
- A Wisconsin visitor can identify a relevant official next step with plain-language labels and clear destination behavior.
- Guard/Reserve service is not silently converted to active-duty separation; returning from orders is distinct from leaving the military.
- State programs, federal programs and local assistance are labeled accurately; a state's National Guard-specific program is not offered as a universal Reserve benefit.
- All state-help categories expose supported official next steps, while unknown individual eligibility stays with the deciding agency.
- The existing plan remains member-controlled; no silent replacement, no new accounts, tracking, precise location, model API or benefit eligibility engine.
- Refresh and return navigation retain orientation. Documents and existing Wisconsin work-cost follow-through remain intact.
- Local checks pass at 320 and 375 CSS-pixel targets, both themes, keyboard access and zero horizontal overflow. Manual assistive technology and real-member usefulness remain separate, unmeasured evidence.
